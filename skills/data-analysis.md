# Skill: local data analysis

Analyze the supplied local dataset reproducibly.

1. Inspect schema, types, units, row count, nulls, duplicates, and obvious encoding errors.
2. State the population/sample represented and any filters before computing conclusions.
3. Use data/math tools for all calculations. Preserve enough precision to reproduce results.
4. Report denominator and units beside every rate or average.
5. Check outliers and missingness before comparing groups.
6. Distinguish association from causation.
7. Provide the exact query/expression or transformation behind key figures.

Output: executive result, data quality, key measures, comparisons, caveats, and reproducible steps. Do not write back to the source unless explicitly requested and approved.
